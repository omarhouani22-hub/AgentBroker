# AgentVault — 30-day customer validation sprint (draft, no outreach authorized)

Status: **PREPARED ONLY**. No messages sent, signups claimed, payments enabled, or production changes.

## Hypothesis
Independent AI-agent developers and early AI startups may pay for **recoverable, durable agent state** when agent runs fail, hosts restart, or state must move between environments. Do not claim seamless execution continuity, production readiness, or verified recovery.

## One offer to test
**AgentVault — Persistent Memory & Recovery for AI Agents**
> When an agent loses state after a crash or deployment, recovering it should be predictable and verifiable. We are interviewing developers about checkpoint recovery, restore tests, and auditability. This is research, not a live storage service.

Initial pricing hypothesis to discuss, **not to charge**: Developer $19/month, Startup $99/month, Growth $299/month, Business $999+/month. Ask what outcome and failure cost justify a purchase, not whether the respondent merely likes the idea.

## Who qualifies
A developer who has deployed at least one autonomous or semi-autonomous agent and has personally faced state loss, memory drift, broken checkpoint restoration, or deployment migration risk in the last 90 days. Avoid generic AI enthusiasts without operating experience.

## Five interview questions (15 minutes)
1. Tell me about the **last actual incident** where an agent lost state or failed to recover. What broke?
2. How did you recover? How much engineering time or customer impact did it cost?
3. What do you use now (database, vector store, checkpoint framework, snapshots)? What is still missing?
4. If the same failure happens next week, what measurable result would justify buying an independent recovery service?
5. Would you commit to a **non-binding design-partner trial** after we pass real isolated restore/security gates? What would you need to see first?

Record verbatim incident evidence, stack, impact, alternatives, and follow-up consent. Never request API keys, credentials, or customer datasets.

## Evidence thresholds (30 days)
- 30 qualified people identified and individually approached with approval.
- 10 completed discovery interviews.
- At least 5 independent, specific costly incidents supported by respondent descriptions.
- 3 serious design-partner trial requests (with security/recovery conditions explicit).
- 2 indications of willingness to pay tied to a specific outcome, **not** casual compliments.
- No sales or customer data uploads before actual isolated restore, durable storage, CI, and security gates pass.

## Decision after 30 days
**Proceed** only if the incident evidence, trial demand, and technical release gates are credible. **Revise positioning** if the pain is real but existing tools solve it cheaply. **Stop** if the audience cannot name costly incidents or will not trial after a clear proof. Avoid further Clara/visual polish until evidence changes.
