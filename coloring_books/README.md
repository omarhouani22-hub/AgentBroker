# Coloring book business pivot

Goal: validate a first paid sale, then target $200 monthly royalties. Preserve Clara and existing AgentVault code; no production deployment or paid services.

## Pipeline
1. Record marketplace demand evidence, competing titles, pricing, and differentiation. Do not fabricate demand or scrape in violation of terms.
2. Select one audience and create an original book brief.
3. Generate original line art with documented provenance and commercial-use rights.
4. Assemble print-ready interior and cover using current KDP trim, bleed, margin and spine specifications.
5. Check page count, image resolution, duplicate artwork, print preview, rights and AI disclosure.
6. Export a publishing package with metadata and a manual approval checklist. No automated login or submission unless officially supported and authorized.
7. Track actual royalties and costs from seller-provided reports. Amazon handles payouts to the verified payment account; never collect bank credentials in this repository.
